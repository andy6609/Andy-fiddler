WireScope

Follow one HTTP request all the way down to the bytes on the wire.

WireScope is a traffic inspector I'm building in C++. Pick a request the proxy recorded, then keep going down: the TCP connection it used, the packets that made up that connection, and the byte offset of every header field.

Open the demo inspector Source on GitHub

This website can't see your traffic. WireScope runs on your own machine as a local proxy and packet capture. What you can open here is an offline report it exported. The viewer and the data are packed into one HTML file, so it works without the engine.

What's in the demo

  • 11 requests sent with curl through WireScope to test servers on 127.0.0.1. They cover two made-up agent turns (the second one carries a tool call and its result), an event stream, a gzip body, chunked with a trailer, a 1.5 MiB body that hits the 1 MiB capture limit, three HTTP/2 streams on one connection, and a refused connection. No real AI service is involved.
  • 12 packets from a hand-built pcap: a TCP conversation in which one segment arrives out of order, one is retransmitted and one is missing, plus a DNS query. They aren't linked to the requests above, because the demo was recorded on a machine without capture permission.

Things to try

  1. Click request #2 → Request → Messages to see the conversation inside the body, tool call included.
  2. Tick #1 and #2 → Compare. Type metadata.session_id into the ignore box and watch the diff say what it ignored.
  3. Request #3 → Response → Events. Type delta.text to join the streamed text.
  4. All packets → packet #5 → hover the fields to light up their bytes, then open TCP stream. The 21 bytes the capture never saw show up as a gap, not as made-up data.

Run it yourself

git clone https://github.com/andy6609/Andy-fiddler
cmake -S Andy-fiddler -B build     # needs CMake, a C++17 compiler, OpenSSL 3, nghttp2
cmake --build build -j
./build/WireScope --sample         # then open http://127.0.0.1:17890

Windows build steps, client setup and what's verified so far are in the README.

Built and tested on macOS and on a GitHub Actions Windows runner. Not yet run on a Windows desktop, and not yet pointed at real AI clients. That's next.
